# Cover Art Video Maker
Standalone Windows 10/11 utility that combines cover artwork and an audio track into an H.264/AAC MP4 locally.

## Features
- JPG/PNG/WebP cover art
- MP3/WAV/FLAC/M4A/AAC/OGG audio
- YouTube 1920×1080, square 1080×1080, vertical 1080×1920
- Static artwork or subtle animated zoom
- Bundled FFmpeg in the installer
- No server, upload, account, or subscription required

The GitHub Actions workflow builds a self-contained Windows x64 application and Inno Setup installer.
